# Genio Institute (Apps Script web app)

Google Apps Script web app (HtmlService). `Code.gs` serves pages; each `Module*.html` is included into `Dashboard.html`. `Config.html` holds shared tokens, components, Supabase helpers, and the shared UI layer for popups/buttons. Deploy by importing files into Apps Script (`importProjectFilesFromDrive` in `Export.gs`), then create a new deployment version. Keep all element IDs and JS hooks intact when restyling. Product requirements and build status live in `docs/PRD.md` (v5); update its Section 14 status when a module changes.

## Design preferences (from the owner, apply to every page)

Reference implementations: `Login.html`, `ModuleHome.html`, `ModulePresensi.html`.

The Tagihan sync bills unlinked pertemuan on the open invoice of that kontrak, or creates the next urutan when every invoice of the month is paid. Urutan 2+ shows a "Tagihan tambahan" tag, the number gets a suffix (`INV-<first invoice>-2`, `REC-<first receipt>-2`), the documents carry a note pointing to the paid first invoice, and every line lists its pertemuan dates. Pertemuan on a paid invoice are locked by trigger `presensi_lock_ditagih` (no status, date, time, contract or jenis change, no delete); the Presensi menu shows a "Sudah ditagih" chip, a lock icon instead of edit, and a popup explaining why (`psShowLockInfo`). Linking `invoice_id` alone does not recalculate nominal (early return in `presensi_before_write`).
- Kirim laporan (table `laporan_kirim`, migration `supabase/migrations/20261009_laporan_kirim.sql`, applied 9 Oct 2026): third Presensi tab for kepala unit, manajer and super admin (the button `#ps-kirimTabBtn` is removed for other roles in `psInit`). One row per presensi marked terkirim (unique `presensi_id`, `cara` satuan/rekap, `mode` link/file, `isi` per_pertemuan/rekap, `rekap_url`); RLS lets manajemen and the kepala unit of that presensi's unit select, insert and delete. "Batalkan tanda" deletes the row. Rekap PDFs come from `generateRekapLaporanPdf` in `Code.gs` (folder "Rekap Laporan Belajar" inside the Laporan Belajar folder; the file name carries a key of the presensi ids so a follow-up rekap never overwrites a link already sent), and "Unduh" uses `getLaporanFileBase64` (only PDFs named `Laporan_Belajar_*` or `Rekap_Laporan_Belajar_*`) so the browser saves the PDF without opening Drive. PDF generation is deduplicated in the browser (one pending request per rekap key or per presensi), because regenerating a file with the same name trashes the previous one. WhatsApp messages: greeting by WIB hour, the line that tautan materi and catatan pembelajaran open from the PDF (only when a laporan has one), and the signature "Tertanda, <Kepala Unit N | Manajer>, <Mr./Ms. from users.jenis_kelamin> <nama>, Genio Institute".
